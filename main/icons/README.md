# Icon sources

`bitcoin.svg` is the unmodified BTC color icon from
[Cryptocurrency Icons](https://github.com/spothq/cryptocurrency-icons/blob/master/svg/color/btc.svg),
also distributed through Iconify's Cryptocurrency collection. The upstream
collection is released under [CC0 1.0 Universal](https://github.com/spothq/cryptocurrency-icons/blob/master/LICENSE.md).

The Cutout app icons and logo are project assets.
